# 🍎 Food Quality Prediction

A machine learning-based web application that analyzes food images and predicts their quality category. The application helps users understand whether a food item is healthy or unhealthy and provides useful recommendations.

## ✨ Features

- 📷 Upload a food image for analysis
- 🤖 Machine learning-based food quality prediction
- 🥗 Food quality classification
- 🍽️ Portion-size guidance
- 💡 Food recommendations
- 🌐 Simple and user-friendly web interface

##  Technologies Used

- Python
- Flask
- TensorFlow / Keras
- NumPy
- Pillow (PIL)
- HTML
- CSS
